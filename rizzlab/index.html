How BYOK pricing works

RizzLab runs on your OpenAI, xAI, or Anthropic key — pasted once, stored only in this browser, never on our servers. A full session (photo ranking + bio rewrites) costs roughly $0.01–0.03 of your own API credit. We charge for the coaching engine, not the tokens.

Bring your own key

Pick a provider, paste a key. It stays in this browser's local storage — it is never sent to our servers. Every AI call goes straight from your browser to the provider.

New to API keys? OpenAI keys · xAI console · Anthropic console. Set a small spend limit (e.g. $5) on your provider account.
Heads up: Anthropic's API sometimes blocks direct browser calls (CORS). If the key test fails below, OpenAI or xAI will work fine — or run Anthropic through a tiny proxy.
