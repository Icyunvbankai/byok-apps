FAQ

Do I need an API key?
Yes — that's what makes it cheap for you. A key takes 30 seconds to create and a full analysis costs a few cents of your own credit, instead of us marking up inference 100x.

Is this legal advice?
No. CounterOffer is a negotiation coach, not a lawyer. It flags clauses worth asking about — non-competes, IP assignment, arbitration — but have an employment attorney review anything binding.

What if my letter is missing numbers?
Anything the letter doesn't state is labeled "not specified — ask about this." We never invent comp figures.
